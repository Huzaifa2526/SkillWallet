## Reporting a Vulnerability

If you identify a security issue, vulnerability, or accidental exposure of credentials within this repository:

1. **Do not create a public GitHub issue.**
2. Report the vulnerability privately to the project author, **Huzaifa Sheikh** (GitHub: [@Huzaifa2526](https://github.com/Huzaifa2526)).
3. Provide a detailed summary, including affected files, reproducibility steps, and potential impact.
4. All verified reports will be investigated and addressed promptly.

## Secrets and Credentials Policy

- **No Secrets Allowed:** This project does not require or accept private API keys, database credentials, authentication tokens, passwords, or personal access tokens.
- Any pull request or commit containing credentials or sensitive data will be rejected immediately.
